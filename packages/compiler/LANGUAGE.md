# Banger language

.banger is plain text music with a looping song timeline. It has no imports, JavaScript, shell commands, audio-file loading, or external samples. Every value statement ends with a semicolon. Blocks need no trailing semicolon. Numeric values support arithmetic and let variables.

Begin with tempo 120; meter 4/4; Tempo is 20 to 300 BPM; only 4/4 is supported. Names are unique identifiers matching [A-Za-z_][A-Za-z_0-9]* with at most 64 characters.

Use up to 16 tracks. Each track needs exactly one source and one base pattern. Example: track kick { sound "drums/kick"; rhythm "x . x ."; gain .6; }. Sounds: drums/kick, drums/snare, drums/hat, drums/clap, drums/tom, drums/open-hat. Instruments: synth/bass, synth/pluck, synth/lead, synth/pad, synth/bell, synth/organ, synth/keys, synth/808-bass, synth/marimba, synth/woodblock, synth/downlifter, synth/impact, synth/muted-guitar. Instruments use notes "C2 . G2 ." or piano; sounds use rhythm. x means hit and . means rest. Pitches use A to G, optional # or b, and octave, within MIDI 0 to 127.

Built-in synth recipes: synth/808-bass is a pitched sine/sub bass with a short downward pitch transient, restrained drive and a 1.6-second decay to silence. Use C1 to C3 and piano durations for bass lines. Glide defaults to zero; add it explicitly for slides. synth/marimba is warm mallet percussion; synth/woodblock is a shorter wooden strike. synth/downlifter is a falling noise sweep whose filter follows the note gate; synth/impact combines a pitched thump with decaying noise. Use a single C2 note for impacts and a held C4 for downlifters. synth/muted-guitar is an approximate Muted Synth Guitar voice for short rhythmic chords, not a sampled or physical guitar. All six use instrument with notes or piano, work offline, and accept numeric step locks without a synth block. A synth or modular block replaces the recipe using Init defaults, rather than merging with it. modular ""; disconnects it.

Each base pattern defaults to one bar. Optional bars 4; makes it four bars. Phrase length is 1 to 64 whole bars, four quarter-note beats per bar. Rhythm/notes strings have 1 to 64 evenly spaced steps across the entire phrase. For chords, held notes and velocity, use piano { note "C4" start 0 duration 2 velocity .8; note "E4" start 0 duration 2 velocity .6; }. Every note requires pitch, start, duration and velocity in that order. Start must be >= 0 and < bars*4, duration > 0, end <= bars*4, velocity 0 to 1. Up to 128 piano notes per phrase and 4096 per file. piano {} is silent. Do not mix rhythm, notes and piano in one pattern.

Inside a track, add up to 32 named alternatives: pattern chorus { bars 4; notes "C4 E4 G4 B4"; }. Named patterns inherit the track source, gain, pan, effects, groove, sends and automation; pattern blocks contain only bars and rhythm/notes/piano. Keep a base pattern in the track even when using named alternatives.

Arrange with section verse { bars 8; play kick; play keys; } and section chorus { bars 8; play kick; play keys chorus; }. Each section lists tracks once; an optional second identifier selects that track's named pattern. Omitted tracks are silent. Each selected pattern repeats to fill the section; a final partial repetition stops at its boundary. Empty section bindings produce silence. Add song { play verse 2; play chorus; } to order sections, with optional integer repeat counts. Up to 64 sections, 64 bars per section, 128 timeline entries and 1024 total song bars. A song must have at least one entry. Without song, base patterns repeat to the longest base phrase; named patterns and sections alone do not change playback. Forward references are allowed. The compiler limits expansion to 65536 potential note/hit events.

Track and bus gain ranges 0 to 1, pan -1 to 1. Effects run in source order, once per kind: effect reverb { mix .15; }, effect delay { time .375; feedback .4; mix .25; }, effect filter { cutoff 2500; resonance 1; }, effect eq { low -3; mid 0; high 2; }, effect compressor { threshold -24; ratio 4; attack .01; release .1; knee 20; }, effect distortion { amount .2; mix .3; }. All mixes and distortion amount are 0 to 1. Delay time .01 to 2 seconds, feedback 0 to .85. Filter cutoff 20 to 20000 Hz, resonance 0 to 20. EQ low/mid/high are -24 to 24 dB. Compressor threshold -100 to 0 dB, ratio 1 to 20, attack/release 0 to 1 seconds, knee 0 to 40 dB. Optional sidechain kick; inside compressor uses an existing track's audio as detector input. Effects can omit parameters to use defaults.

Declare up to 8 buses: bus music { gain .8; effect eq { low -3; mid 0; high 1; } } bus space { gain .5; effect reverb { mix 1; } }. A track's output music; routes its dry output to that bus. Without output it routes to master. send space .2; adds a parallel send, gain 0 to 1, on tracks or buses. Buses always output to master and may send to other buses. Each track/bus can send to up to 8 distinct buses. Routing cycles and unknown references are rejected. Bus blocks accept gain, pan, effects, sends and automation.

Track automation repeats from beat 0 for each phrase clip; bus automation follows song beats. Example: automation "filter.cutoff" { interpolation linear; point 0 300; point 8 5000; }. Points must have strictly increasing nonnegative beat positions, max 4096 beats. Values stay within the corresponding parameter range. Interpolation is linear by default, or step to hold each point's value until the next. Values clamp to first/last point outside the curve. Points can extend beyond shorter phrases to serve longer named patterns; shorter phrases sample only their active interval. One curve per target, up to 16 curves and 128 points per curve. Point syntax is point BEAT VALUE; use parentheses around arithmetic in BEAT, for example point (1 + 1) -.5;.

Automation targets: gain, pan, pitch, filter.cutoff, filter.resonance, reverb.mix, delay.mix, delay.time, delay.feedback, eq.low, eq.mid, eq.high, compressor.threshold, compressor.ratio, distortion.amount, distortion.mix. Quote the target. pitch is a semitone offset from -48 to 48 and is track-only. An effect target requires that effect in the same track/bus. Automation values are absolute parameter values, not multipliers.

Optional track groove { quantize .25; swing .2; humanize .01; seed 42; } adjusts note/hit starts. Quantize is a beat grid from 1/128 to 4. Swing 0 to 1 delays alternate grid subdivisions by up to half a subdivision; when no quantize is set, swing uses an eighth-note grid of .5 beats. Humanize is max signed timing jitter, 0 to .5 beats. Seed is a whole number from 0 to 4294967295. Same seed and event index yield the same timing. Groove does not change stored piano notes or phrase length.

The compiler is the authority for accepted syntax. Preserve unrelated tracks, patterns, sections, mixer routing and automation during edits.

Synth presets in the Sound tab include Synth Brass, Flute Lead, Chiptune Lead, String Ensemble, Kalimba Pluck and Noise Riser, plus bass, keyboard and percussion recipes. These are synthesized sounds. Selecting a preset writes its configuration into the track, rather than adding a new instrument source name. Use long piano notes for strings and risers. A track can replace its source voice with synth { enabled 1; osc1 "square"; attack .002; decay .09; sustain .25; release .035; }. Omitted synth controls use Init defaults. tone ranges from 0 to 1 and scales both oscillators and the sub oscillator; noise is independent. filterSweep ranges from -1 to 1 and sweeps the cutoff by up to five octaves over the held note, clamped to the audio sample rate. A nonzero filterSweep replaces filterEnv's attack-and-return motion. filterDecay is 0 to 2 seconds; zero returns the filter envelope at note-off, while a positive value gives a shorter filter decay after its attack. Existing patches default to tone 1, filterSweep 0 and filterDecay 0. For a noise-only riser, use synth { enabled 1; tone 0; sub 0; noise 1; cutoff 300; filterEnv 0; filterSweep 1; lfo1Depth 0; attack 1.6; decay .1; sustain 1; release .15; }.

## Music Box, Clavinet and 808 Bass

Sound presets Music Box, Clavinet and 808 Bass use existing synth configuration and the same preview, playback and offline WAV renderer. Music Box and Clavinet are preset names, not instrument source names. Keep a valid source such as instrument "synth/keys"; and encode the synth block below. Do not write instrument "synth/music-box", instrument "synth/clavinet", or a preset statement. 808 Bass also has the existing instrument "synth/808-bass"; shorthand. Selecting any of these in the Sound tab saves its full configuration. A modular display name alone does not select a recipe; modular "Music Box" { ... } must contain its controls. Stage identity comes from effective synth values, including step locks, not track or patch names.
Music Box: bright, pitched bell overtones. Start in C4 to C7 with 0.5 to 2 beat notes, velocities .4 to .9. Attack .003 seconds, decay .95 seconds, sustain 0 and release .12 seconds. Short gates truncate the decay. Adjust fm gently, keep fmRatio at integer 3 for the tuned overtones, and use cutoff, decay and release for brightness and note endings.
Clavinet: bright, short plucks for syncopated notes and chords in C3 to C5. Try 0.125 to 0.5 beat piano durations and velocities .4 to .9. Attack .002, decay .18, sustain 0, release .045 seconds. filterEnv .65 with filterDecay .055 gives the fast brightness decay; cutoff and velocityFilter control bite. Keep drive restrained, around .035. Use simultaneous piano notes for chords.
808 Bass: use C1 to C3, usually one note at a time, with 0.5 to 4 beat gates and velocities .5 to .9. The sine body and sub .18 stay pitched; pitchEnv 12 drops to the played note in pitchDecay .035 seconds. Decay 1.6 and sustain 0 fade held notes to silence. Shorter gates end earlier through release .12. Keep drive near .025 and lower gain for layered bass. Optional glide slides from the previous pitch. All envelope controls are seconds; piano durations are beats. Numeric step locks such as lock 0 { cutoff 5000; decay .5; } apply to notes-string steps, not piano notes.
Exact preset recipes, with other fields using Init defaults:
Music Box: synth { enabled 1; osc2 "sine"; mix 0; fm 0.14; fmRatio 3; detune 0; sub 0; cutoff 11000; resonance 0.1; filterEnv 0; lfo1Depth 0; attack 0.003; decay 0.95; sustain 0; glide 0; volume 0.65; }
Clavinet: synth { filterDecay 0.055; enabled 1; osc1 "sawtooth"; mix 0.3; drive 0.035; fm 0.04; detune 0; sub 0; cutoff 1100; resonance 0.4; filterEnv 0.65; velocityFilter 0.25; lfo1Depth 0; attack 0.002; decay 0.18; sustain 0; release 0.045; glide 0; }
808 Bass: synth { enabled 1; osc2 "sine"; mix 0; drive 0.025; detune 0; sub 0.18; cutoff 900; resonance 0; filterEnv 0; lfo1Depth 0; attack 0.004; decay 1.6; sustain 0; glide 0; pitchEnv 12; pitchDecay 0.035; volume 0.65; }
Additional synth controls: tone 0 to 1 scales oscillators and sub, but not noise. filterSweep -1 to 1 moves cutoff by up to five octaves over the gate, replacing filterEnv when nonzero. filterDecay 0 to 2 seconds controls the return after filter attack; zero returns at note-off. These three presets use tone 1 and filterSweep 0.
